# Проверка клиента

Проверено 17 сентября 2026 года.

- Пакет собирается в wheel и устанавливается в отдельный каталог.
- Автоматические тесты используют локальный HTTP-сервер и поддельный worker.
  Проверяются все обёртки операций, параметры заданий, авторизация, ошибки HTTP,
  отмена, таймауты, gzip, SHA-256, очистка неполных файлов, разбиение поиска,
  пакетные свойства и связи, checkpoints и сохранение без hard link.
- На `https://360pilot.ru/bim-bridge` выполнена небольшая сквозная проверка.
  Каталог вернул 12 моделей. Для модели УПС выбраны 20 частей с `-Piping` в имени.
  Общий каталог сервера имел состояние `partial`.
- Поиск вернул 3 элемента при лимите 3 и корректный `Truncated=true`.
  Свойства и связи этих элементов получены без пропусков и предупреждений.
- Исходный файл скачан. Размер — 373966 байт. Проверка целостности прошла.
  Excel-операция вернула один выбранный лист `TDSheet`.
- После проверки worker находился в `WAITING`. Активных заданий, очереди и
  незавершённых загрузок не было.

Полная повторная выгрузка модели в рамках этой проверки не запускалась.
Диагностические операции проверены локальными тестами. На рабочем worker
capability `diagnostics` не включена. Сам Colab и установка из GitHub не
проверялись: репозиторий ещё не опубликован. Проверена установка из wheel.
